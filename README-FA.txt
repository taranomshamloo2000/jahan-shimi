جهان شیمی — بسته آماده انتشار
================================

محتویات:
- index.html : صفحه اصلی جهان شیمی
- games/periodic-world.html : بازی PERIODIC WORLD | جهان عناصر
- games/periodic-table-challenge.html : چالش بزرگ جدول تناوبی مندلیف

انتشار عمومی با GitHub Pages:
1) در مخزن GitHub به Settings > Pages برو.
2) در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کن.
3) Branch را main و پوشه را /(root) بگذار و Save کن.
4) چند دقیقه صبر کن تا GitHub آدرس عمومی سایت را فعال کند.

نکته مهم:
- سایت و فایل‌های آن عمومی خواهند بود؛ اطلاعات شخصی، رمز، شماره تلفن یا فایل خصوصی را در مخزن قرار نده.
- عمومی‌شدن سایت با پیدا شدن فوری در جست‌وجوی گوگل یکی نیست. پس از انتشار، سایت را در Google Search Console ثبت و مالکیتش را تأیید کن؛ سپس از URL Inspection درخواست ایندکس بده. گوگل زمان مشخصی برای نمایش تضمین نمی‌کند.
- بخش انجمن فعلاً معرفی/در حال راه‌اندازی است. برای ثبت واقعی حساب، نظر و عکس باید Firebase یا سرویس مشابه پیکربندی و قوانین امنیتی آن تنظیم شود.
